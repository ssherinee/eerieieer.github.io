# A web photobooth that put you in a Persona 3 game
Live at https://p3.eerieieer.art

This is a fan-made project purposed for my beloved boyfriend's bday (ily)  
The artwork is inspired by Persona 3 (Reload and Portable) and belongs to Atlus.

### How it works

The app is a single page with three screens:

1. **Home:** a title image with a "Press Start" button.
2. **Capture:** a live camera preview inside the frame, with three modes at the bottom:
   - **Photo:** 3-2-1 countdown, then saves one JPEG
   - **GIF:** 3-2-1 countdown, then captures about 16 frames over roughly 2.4 seconds and builds an animated GIF
   - **Upload:** choose an image from your device and it's placed inside the same frame
3. **Result:** preview the picture, then **download** it, **retake**, or go back **home**

### Tech

This is a static client-side web app built on plain HTML, CSS and JavaScript with no framework and no build step :>   
Absolutely no backend #lolz
